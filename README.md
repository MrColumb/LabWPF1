## Лабораторные работы 1&2
Приложение для демонстрации привязок WPF. Ветки:
- master: ручная реализация приложения паттерном MVVM
- community-toolkit: реализация приложения паттерном MVVM с помощью библиотеки Community.Toolkit.MVVM
- translate-resx: локализация приложения с помощью файлов ресурсов (RESX)
- translate-dictionary: локализация приложения с помощью словаря ресурсов (XAML)
- translate-codingseb: локализация приложения с помощью внешней библиотеки CodingSeb.Localization
